# Velaris V0.0.3

Historic snapshot of Velaris V0.0.3.

This release introduced the first JavaScript enhancement layer, the generated Spotlight hero, smart row classification and custom rail navigation.

The archived CSS and JavaScript loaders reference commit `7cd3eec5592ff453dd036051d8f9938371dba35a`, which contains the V0.0.3 distribution files.

Included here:

- `velaris.css` — pinned V0.0.3 CSS loader
- `velaris.js` — pinned V0.0.3 JavaScript loader
- `velaris-loader.user.js` — frozen Tampermonkey loader for V0.0.3
