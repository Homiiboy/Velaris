# Gemeinsame Velaris-Assets

Hier kannst du Grafiken für die gemeinsame Smartphone- und TV-App hochladen.

| Ordner | Inhalt |
| --- | --- |
| `logos/` | Velaris-Logo und App-Icon |
| `banners/` | TV-Banner und weitere breite Grafiken |
| `avatars/` | Profilbilder und Avatare |

Auf GitHub den passenden Ordner öffnen und **Add file → Upload files** auswählen. Verwende eindeutige Dateinamen, zum Beispiel `VelarisLogo.png` oder `VelarisBannerTV.png`.

Dieser Ordner ist der zentrale Ablageort. Neue Dateien werden durch das Hochladen noch nicht automatisch in den Apps verwendet; die Einbindung erfolgt im nächsten Entwicklungsschritt. Die bisherigen App-Assets bleiben bis dahin an ihren bestehenden Pfaden eingebunden.
