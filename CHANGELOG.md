# Changelog

## 0.0.4 — 2026-09-02

- Rebuilt Velaris Spotlight as a rotating multi-title hero.
- Added up to six automatically selected featured titles from the Jellyfin home page.
- Added Spotlight previous/next controls, indicator dots and automatic rotation.
- Added smarter rail controls that reflect whether a row can scroll left or right.
- Added Favorites/Favoriten row classification in addition to Continue Watching, Next Up and Latest.
- Added page-state detection for home, browse, details, player and login views.
- Redesigned the header tabs as a floating streaming-style navigation surface.
- Enlarged Continue Watching and Next Up landscape rows on desktop.
- Improved responsive, hover, keyboard-focus and reduced-motion behavior.
- Updated the Tampermonkey loader to v0.0.4 with versioned asset URLs for cleaner cache updates.
- Archived the v0.0.3 userscript loader under `HistoricVersions/V0.0.3/`.

## 0.0.3 — 2026-09-02

- Migrated the interface to the new Velaris identity.
- Added the first JavaScript enhancement layer.
- Added a generated cinematic Spotlight hero.
- Added smart row classification for English and German Jellyfin labels.
- Prioritized Continue Watching and Next Up rows below the hero.
- Added custom horizontal rail controls.
- Added responsive and reduced-motion handling.
